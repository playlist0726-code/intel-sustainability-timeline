# Intel Sustainability Timeline and Global Impact

A responsive, interactive website created for Web Design Projects 2 and 3. The original Flexbox timeline remains intact and is expanded with Bootstrap 5.3.8, an RTL-aware language preview, a responsive three-column impact section, an accessible newsletter form, a Bootstrap accordion, and a structured footer.

## Project 3 features

- Bootstrap grid that shifts from three columns to one column across screen sizes
- Automatic `dir="rtl"` or `dir="ltr"` updates when the page language changes
- English and Arabic direction-preview controls for quick evaluation
- Descriptive image alternatives, semantic landmarks, a skip link, strong contrast, visible focus styles, and reduced-motion support
- Accessible form labels, instructions, inline error messages, and live status feedback
- Bootstrap accordion for added interactivity
